# Internship Test Game

A short Unity game developed as part of the internship selection test. The game was built following the provided game design document.

---

## 🎮 Gameplay Summary

- Players drag and drop vegetable items to their corresponding targets (the rabbit's basket).
- If a vegetable is dragged close enough to the correct target, it snaps into place.
- If incorrect or dropped far from the target, it returns to its original position.

---

## 🐰 Animation Flow

- **Idle**: Default state when no action is being performed
- **Happy**: Played when a vegetable is correctly placed
- **Sad**: Played when a vegetable is returned to the original position
- **Pouring**: After every round (3 correct matches)
- **Jumping**: After round 3 + after Pouring animation

---

## 🔁 Game Structure

- 3 rounds total  
- Each round has 3 vegetables to be matched correctly  
- After completing all 3 rounds, final animation is triggered

---

## 📺 UI & Scene Flow

- **Main Menu**: Has a "Play" button that navigates to Gameplay scene  
- **Gameplay Scene**: Contains a "Back" button to return to Menu  

---

## ⚙️ Tech & Tools

- Unity (version 6.1)  
- Basic Unity Animator system  
- Drag & drop logic via Collider + custom scripting  
- Aseprite

---

- Game logic, drag system, and animation triggers are functional as per brief.
